# test 100문항에서 확인한 입력 누락과 표기 문제

**평가한 100문항 중 8개는 그림을 보라고 하지만, 모델 입력에는 그림이 없었습니다.** 문제를 제외하거나 바꾸지 않고 같은 100개로 평가했습니다. 따라서 결과는 일부 그림이 빠진 텍스트 입력 조건의 성능입니다.

2026년 9월 21일에 고정한 [실제 test 문제](../repro/reference/test/questions.jsonl)를 점검했습니다. MedQA는 의료 객관식 문제 데이터이며, 이번 입력에는 문제 본문·선택지 4개만 들어갔습니다. 문장을 붙이는 조건에서는 여기에 생성한 문장을 더했습니다. 데이터의 정답표는 모델 답변을 채점하는 데 사용했습니다.

## 그림이 빠진 8개 문항

아래 ID 앞에는 모두 `medqa-usmle4:test:`가 붙습니다.

| 문항 ID | 본문이 참조하지만 입력에는 없는 자료 |
|---|---|
| `00000821` | 뇌 조직 사진과 화살표 표시 |
| `00000716` | 피부 발진 사진 |
| `00000311` | 생검 조직 사진 |
| `00000484` | 왼발 사진 |
| `00000126` | 머리 CT 영상 |
| `00001197` | 12유도 심전도 |
| `00000640` | 말초혈액 도말 사진 |
| `00000256` | 두피 병변 사진 |

그림이 없다고 반드시 풀 수 없는 문제라는 뜻은 아닙니다. 텍스트만으로 충분한지는 판정하지 않았습니다. 특히 `00000640`에는 검사 수치가 있지만, 별도로 언급한 혈액 도말 사진은 없습니다.

## 표나 수치가 실제로 들어 있는 경우는 구분했습니다

`00000877`의 환자별 호흡수, `00000413`의 전해질 수치, `00000130`의 혈액검사 값은 텍스트에 있습니다. `00000375`, `00000584`, `00001230`도 영상 소견을 문장으로 설명합니다. `shown`, `below`, `CT` 같은 단어만 보고 자료 누락으로 분류하지 않았습니다.

## 원문에서 발견했지만 고치지 않은 표기

- **10문항**은 마지막 물음표 뒤에 큰따옴표가 남아 있습니다: `00000130`, `00000527`, `00000877`, `00001109`, `00000245`, `00001176`, `00001200`, `00001181`, `00000353`, `00000058`.
- `00001230`의 온도는 원문에 `39.1°C (102.4°C)`라고 적혀 있습니다. 표기가 의심되지만 임의로 고치지 않았습니다.
- **17문항**에 실제 줄바꿈이 있습니다. 줄바꿈이 문자 `\n`으로 잘못 남은 경우는 없었습니다.
- ID와 질문 내용은 각각 **100개 모두 고유**했습니다. 빈 질문이나 빈 선택지는 없었습니다.

이 점검은 본문에서 참조한 자료가 실제 입력에 있는지 확인한 것입니다. 의료 전문가가 문제와 정답의 정확성을 검토한 결과는 아닙니다. 8문항을 따로 분석한다면 [전체 100문항 결과](TEST_RESULTS_KO.md)와 구분해 보고해야 합니다. 당시의 더 상세한 목록은 Git 태그 `reference-20260921`에 보존했습니다.
