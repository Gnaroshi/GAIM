## 실제 텍스트 입력에 없는 시각 자료 참조

## 원문 형식에서 관찰한 사항

- 다음 **10문항**은 질문 끝의 물음표 뒤에 큰따옴표가 추가로 남아 있다. `medqa-usmle4:test:` 뒤의 ID는 `00000130`, `00000527`, `00000877`, `00001109`, `00000245`, `00001176`, `00001200`, `00001181`, `00000353`, `00000058`이다. 원문을 그대로 보존했다.
- `medqa-usmle4:test:00001230`에는 온도가 원문 그대로 `39.1°C (102.4°C)`라고 표기되어 있다. 서로 다른 두 값에 같은 단위가 붙은 표기상 의심 사례로 기록하며, 어느 값을 고쳐야 하는지 판정하거나 교정하지 않았다.
- 실제 줄바꿈이 들어 있는 문항은 **17개**였다. 줄바꿈이 역슬래시와 n이라는 두 문자로 남은 사례는 발견하지 않았다. 줄바꿈 자체를 자료 누락으로 보지 않았다.
- 단순 구조 점검에서 ID 100개와 질문 해시 100개가 각각 고유했으며, 빈 질문이나 비어 있는 A~D 선택지는 발견하지 않았다. 이는 내용의 의학적 품질을 검증한 결과가 아니다.

## 점검 방법과 해석 범위

JSONL의 100개 레코드를 읽고 그림·사진·화살표·영상·도표·심전도·파형을 나타내는 참조 표현을 검색한 뒤, 후보 문항의 본문과 선택지를 직접 확인했다. 숫자 표가 실제로 이어지는 경우와 영상 소견이 문장으로 기술된 경우를 구분했다. 원문 필드와 실제 메시지 생성 방식이 텍스트 입력이라는 점도 확인했다.

이 점검은 고정된 표본의 입력 제약을 설명하기 위한 읽기 전용 점검이다. 의료 전문가의 내용 검토, 원래 이미지의 복원, 모든 잠재적 자료 누락의 완전한 검증을 수행한 것은 아니다. 모델 간 비교에서는 같은 저장 입력을 사용하지만, 이런 공통 입력 제약이 사라지는 것은 아니다. 이번 결과는 **일부 시각 참조 자료가 없는 텍스트 입력 조건에서 얻은 결과**로 해석한다.

후속 분석에서 이 8문항을 별도로 살펴보더라도 전체 100문항 결과와 명확히 구분해야 한다. 이번 점검으로 문항을 제외하거나 교체한 사실은 없다.
