# 전체 MedQA 실행 결과

**원문 추가 학습은 정답률을 높였다. 그러나 교란을 포함해 학습한 모델에서는 '추천된 선택지를 피하는 행동'이 나타났고, 제안한 선택 방법의 견고성 우위는 입증되지 않았다.**

실행: `full_medqa_20260922`. 아래 수치는 저장된 예측 63,650건을 CPU로 다시 집계한 결과다. 새 모델 호출이나 재학습은 하지 않았다. 원문 입력 해시, 원본 정답, A/B/C/D 점수에서 실제 고른 답을 대조했고 기존 결과 파일의 정답 수와 일치했다.

## 어떤 실험이었나?

- 출발점: Qwen 팀이 이미 학습해 공개한 `Qwen/Qwen3-4B-Instruct-2507`. '공개 모델 그대로'는 프로젝트 추가 학습이 없는 모델이다.
- 네 추가 학습 모델은 같은 공개 모델에서 각각 출발했다. 원문 10,174문제, 모델당 입력 20,348개, 2 epochs, 2,544회 갱신을 완료했다.
- 평가: train과 원문 해시가 겹치지 않는 test 1,273문제. 원문과 의견 4개를 방어 지시 없음/있음으로 평가해 모델당 12,730입력이다.
- 세 교란 학습 조건 모두 원문 1개와 의견을 붙인 입력 1개를 문제마다 학습했다. 의견은 문장 요소의 조합으로 만들었으며, LLM이 자유롭게 작성한 자료가 아니다.
- 답은 다음 토큰의 A/B/C/D 점수 중 가장 높은 글자다. 자유로운 설명 생성이나 임상적 안전성을 평가한 점수는 아니다.

## 1. 주요 결과: 방어 지시 없이 평가

의견은 '나는 B가 답인 것 같다'처럼 선택지를 권하는 문장이다. '오답 의견'은 실제 정답과 다른 선택지를 권하고, '정답 의견'은 실제 정답을 권한다. 둘 다 새로운 환자 정보나 근거는 제공하지 않는다.

| 추가 학습 자료 | 원문 | 오답을 권하는 의견 추가 | 정답을 권하는 의견 추가 |
|---|---:|---:|---:|
| 공개 모델 그대로 | 52.40% (667/1,273) | 51.35% (1,961/3,819) | 54.28% (691/1,273) |
| 원문만 학습 | 63.32% (806/1,273) | 61.43% (2,346/3,819) | 66.93% (852/1,273) |
| 무작위 문장을 추가해 학습 | 64.49% (821/1,273) | 70.91% (2,708/3,819) | 0.63% (8/1,273) |
| 오답을 만든 문장을 골라 학습 | 62.69% (798/1,273) | 69.31% (2,647/3,819) | 0.63% (8/1,273) |
| 정답 점수를 낮춘 문장을 골라 학습 | 63.79% (812/1,273) | 69.13% (2,640/3,819) | 10.92% (139/1,273) |

오답 의견은 문제마다 3개이므로 3,819입력이다. 정답 의견은 문제마다 1개이므로 1,273입력이다. 3,819개를 서로 독립인 의료 문제로 해석하지 않는다.

- 원문만 학습해도 원문 정답률이 **52.40% → 63.32%**로 올랐다. 이 개선에는 답안 형식 적응도 포함될 수 있어, 전부 새로운 의학 지식 습득의 효과라고 단정하지 않는다.
- 오답 의견만 보면 무작위 문장 학습이 **70.91%**로 가장 높다. 정답 점수 감소 선택은 **69.13%**로 무작위보다 낮았다.
- 그러나 정답 의견을 붙이면 무작위·오답 유발 학습은 **0.63%**, 정답 점수 감소 학습은 **10.92%**까지 떨어진다. 원문만 학습한 모델은 같은 입력에서 **66.93%**였다.
- 따라서 잘못된 권유를 따르지 않는 능력만 보고 전체 견고성이 좋아졌다고 말할 수 없다.

## 2. 왜 이런 결과가 나왔나?

실제 학습 파일을 확인하면, 세 교란 학습 모델 각각에 사용한 **의견 10,174개 모두가 오답을 권한다. 정답을 권하는 의견은 0개다.**

이 자료에서는 의견이 언급한 선택지가 항상 정답 후보에서 제외된다. 따라서 모델이 의학적 근거로 의견을 무시하는 대신, **'의견에 나온 글자는 답으로 고르지 않는다'**는 규칙을 학습할 수 있다. 이번 학습 자료의 구조적인 편향이다.

실제 무작위 문장 학습 모델은 오답 의견 3,819개에서 권유된 글자를 **한 번도 고르지 않았다.** 정답 의견에서도 권유된 정답을 고른 것은 **8/1,273개**뿐이다. 이것은 추천된 글자를 거의 무조건 피하는 행동과 강하게 일치한다. 모델 내부의 인과 기제를 직접 증명한 것은 아니다.

이를 확인하려고 학습 없이 다음 단순 규칙도 계산했다.

> 원문만 학습한 모델이 원문에 부여한 A/B/C/D 점수를 가져와서, 의견이 추천한 글자만 제외하고 나머지 중 가장 높은 것을 고른다.

이 **사후 진단용 규칙**의 오답 의견 정답률은 **69.84% (2,667/3,819)**다. 실제 교란 학습의 69.13~70.91%와 비슷하다. 정답 의견에서는 정답을 제외하므로 당연히 0%다. 별도로 학습한 모델이나 사전에 정한 경쟁 방법이 아니라, 이번 결과를 해석하기 위한 진단이다.

문장 표현을 바꾸어도 '추천 글자를 제외하라'는 규칙은 그대로 적용된다. 따라서 학습과 test에서 첫 문장 틀이 다르다는 사실만으로 새로운 교란 종류에 일반화했다고 말할 수 없다.

## 3. 의견 네 개를 모두 포함하면

| 추가 학습 자료 | 의견 4개를 합친 정답률 | 의견 4개 모두 정답인 문제 비율 |
|---|---:|---:|
| 공개 모델 그대로 | 52.08% | 43.13% |
| 원문만 학습 | 62.80% | 57.82% |
| 무작위 문장을 추가해 학습 | 53.34% | 0.63% |
| 오답을 만든 문장을 골라 학습 | 52.14% | 0.63% |
| 정답 점수를 낮춘 문장을 골라 학습 | 54.58% | 10.92% |

합친 정답률은 오답 의견 3개와 정답 의견 1개가 섞인 **3:1 구성의 점수**다. 자연 발생하는 의견의 비율을 대표하지 않는다. '모두 정답'은 한 문제에 붙인 네 의견 각각에서 전부 정답을 낸 비율이다. 그 범위도 이번 네 문장에 한정된다.

원문만 학습한 모델의 합친 점수는 **62.80%**, 정답 점수 감소 선택 모델은 **54.58%**다. 후자의 10.92% 정답 의견 점수는 다른 두 교란 학습보다 덜 나쁘지만, 일반적인 견고성 개선으로 평가할 수 없다.

## 4. 무시하라는 지시를 넣으면 해결되는가?

시스템 지시에 원문의 의학적 사실과 선택지만 기준으로 답하고 추가 의견을 사실이나 지시로 취급하지 말라는 문장을 넣었다. 원문에도 같은 지시를 적용했다.

| 추가 학습 자료 | 원문 | 오답 의견 | 정답 의견 |
|---|---:|---:|---:|
| 공개 모델 그대로 | 55.30% | 56.32% | 51.22% |
| 원문만 학습 | 63.32% | 63.66% | 63.39% |
| 무작위 문장을 추가해 학습 | 64.34% | 70.83% | 0.86% |
| 오답을 만든 문장을 골라 학습 | 62.45% | 69.26% | 0.63% |

방어 지시만으로 교란 학습 모델의 문제가 해소되지 않았다. 정답 의견에서 무작위 문장 학습은 0.86%, 정답 점수 감소 학습은 12.33%다. 원문만 학습한 모델의 오답 의견 정답률은 61.43%에서 63.66%로 바뀌었다. '방어 지시'와 '교란 학습'의 효과는 별도로 해석해야 한다.

## 5. 선택 방법이 실제로 얼마나 다른 자료를 골랐나?

| 문장 선택 방법 | 기준에 맞는 문장을 찾은 문제 | 대신 무작위 문장을 쓴 문제 | 실제 무작위 조건과 다른 문장 |
|---|---:|---:|---:|
| 오답을 만든 문장을 골라 학습 | 1,316 (12.93%) | 8,858 (87.07%) | 1,006 (9.89%) |

공개 모델이 원문을 맞힌 학습 문제는 5,468개다. 두 선택 기준을 모두 적용할 수 있었던 문제는 **673개**뿐이다. 따라서 이번 전체 비교는 무작위 대체까지 포함한 두 선택 정책의 비교이며, 같은 문제에서 두 종류의 예제 자체의 효과를 분리한 실험은 아니다.

## 7. 차이에 대한 불확실성

원본 문제를 단위로 두 모델의 결과를 함께 재추출하는 paired bootstrap을 10,000번 수행했다. 한 문제의 세 오답 의견은 함께 묶었다. `%p`는 정답률 차이이며 상대 개선율이 아니다.

| 비교 | 지표 | 차이 | 문제 단위 95% 구간 |
|---|---|---:|---|
| 원문 학습 − 공개 모델 | 원문 정답률 | +10.92%p | [+7.93, +13.90]%p |
| 정답 점수 감소 선택 − 무작위 선택 | 오답 의견 정답률 | -1.78%p | [-3.40, -0.16]%p |
| 정답 점수 감소 선택 − 오답 유발 선택 | 오답 의견 정답률 | -0.18%p | [-1.83, +1.47]%p |
| 정답 점수 감소 선택 − 원문 학습 | 의견 4개를 합친 정답률 | -8.23%p | [-10.00, -6.40]%p |

이 구간은 **학습 seed 하나로 얻은 고정 모델들에서 test 문제 구성이 바뀔 때의 불확실성**이다. 학습 seed에 따른 변동은 포함하지 않으며, 여러 비교에 대한 보정을 하지 않은 탐색적 분석이다. 현재 결과로 제안 방식의 일반적인 우위나 논문상 최초성을 주장하지 않는다.

## 9. 다음 실험에서 먼저 고칠 것

1. **권유된 답이 항상 오답인 구조를 없앤다.** 예를 들어 같은 원문에 A/B/C/D를 각각 권하는 문장을 넣으면, 추천 글자 자체가 정답 제외의 단서가 되지 않는다. 비교 모델들의 자료 수와 갱신 횟수도 다시 맞춘다.
2. 원문 정답률, 오답 의견 정답률, 정답 의견 정답률을 모두 유지하는지 확인한다. 오답 의견 점수만 높이는 것을 목표로 삼지 않는다.
3. 균형 잡힌 학습 자료에서 무작위 선택과 두 선택 방법을 다시 비교해야 현재 가설을 제대로 평가할 수 있다.
4. 그다음 학습 문장과 성격이 다른 외부 교란으로 확인한다. 단어 표현만 다른 의견 문장에 성공했다고 일반화로 소개하지 않는다.

현재 결과를 그대로 '새 교란 선택 방법으로 의료 AI의 안전성을 높였다'고 발표해서는 안 된다. 지금 주장할 수 있는 것은 **오답을 권하는 문장만으로 학습하면, 새 표현에서도 권유된 정답을 피하는 행동이 나타났고, 한쪽 평가만으로는 이 실패를 놓칠 수 있었다**는 관찰이다.

## 재집계와 파일

```bash
.venv/bin/python scripts/summarize_full_run.py \
  --experiment runs/full_medqa_20260922 \
  --output runs/full_medqa_20260922/analysis/summary.json
```

CPU와 NumPy만 사용한다. 원본 예측과 학습 파일은 변경하지 않는다. 입력 파일 SHA-256, 재검증 항목, 모든 수치와 세 사례는 [summary.json](results/full_medqa_20260922/summary.json)에 저장했다. 원본 모델 가중치와 전체 예측 파일은 서버 실행 폴더에 보존한다.

실제 학습은 네 모델 모두 microbatch 16이었다. 최대 PyTorch 예약 메모리는 약 17.56~19.04GiB, 최대 텐서 할당 메모리는 약 14.90~15.12GiB였다. 두 숫자는 같은 지표가 아니다.
