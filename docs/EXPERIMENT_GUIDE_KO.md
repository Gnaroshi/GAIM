# 이 실험이 하는 일

**질문은 두 가지입니다.** 의료 문제에 불필요한 문장을 붙이면 AI가 틀리는가? 그런 입력으로 추가 학습하면 더 잘 버티는가?

## 1. 출발 모델

`Qwen/Qwen3-4B-Instruct-2507`은 Qwen 팀이 사전학습과 후속 학습을 마쳐 공개한 약 40억 파라미터 언어 모델입니다. 우리는 그 가중치를 내려받아 사용합니다. [공식 모델 설명](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)

이 문서에서 **“공개 모델 그대로”는 우리 프로젝트에서 추가 학습하지 않은 상태**입니다. 아무것도 배운 적 없는 모델이라는 뜻이 아닙니다. 공개 모델이 제작 과정에서 어떤 개별 문항을 보았는지는 확인하지 못했습니다. MedQA를 전혀 본 적 없다고 가정하지 않습니다.

## 2. 의료 문제는 어디서 가져오나요?

[MedQA의 영어 4지선다 공개 미러](https://huggingface.co/datasets/GBaker/MedQA-USMLE-4-options)를 사용합니다. 한 문제에는 영어 질문, 선택지 A–D, 정답 문자가 있습니다.

| 용도 | 준비한 문제 수 | 이번 기존 실험에서 실제 사용 |
|---|---:|---|
| 학습용 | 100 | 12개에서 문장 생성 → 네 조건에 모두 쓸 수 있는 10개 선택 |
| 개발용 | 20 | 실행과 설정 점검 |
| 시험용(test) | 100 | 학습 후 성능 비교 |

개발용은 원천 학습 자료에서 따로 떼었습니다. 공식 validation 세트가 아닙니다. 정답이 상충하는 중복 4행은 표본을 뽑기 전에 제외했고, 학습·개발·시험에 같은 원문이 겹치지 않도록 확인했습니다. 원천 행 번호와 정답은 기록에 남깁니다.

## 3. “교란”이란 무엇인가요?

문제와 선택지는 그대로 두고, 별도의 추가 문장을 함께 보여주는 것입니다.

실제 예: **“The patient enjoys browsing Porsche car brochures.”** — 환자는 Porsche 자동차 안내 책자를 구경하는 것을 좋아한다.

이 문장을 넣어도 답이 같아야 한다는 가설을 시험합니다. 실제 test 100개에서는 Porsche 문장 때문에 맞던 답이 틀린 경우가 없었습니다. [원문과 실제 답변](TEST_EXAMPLES_KO.md)

원문을 보존했다고 추가 문장까지 의학적으로 무관해지는 것은 아닙니다. 예를 들어 새 증상이나 약물명을 넣으면 문제의 해석이 바뀔 수 있습니다. 코드로 일부 위반을 거르지만 최종 의학적 검토는 아직 안 됐습니다.

## 4. 문장을 만드는 두 방법

둘 다 **우리가 추가 학습하지 않은 같은 Qwen 공개 모델**에 문장을 만들어 달라고 요청합니다. 생성기는 질문·선택지·정답을 봅니다. 문제를 푸는 모델에는 정답을 알려주지 않습니다.

| 방법 | 다음 문장을 만들 때 받는 정보 |
|---|---|
| 매번 새로 만들기 (`independent`, 이전 명칭: 독립형) | 질문·선택지·정답. 이전 시도의 결과는 받지 않음 |
| 이전 답을 보고 고치기 (`adaptive`, 이전 명칭: 적응형) | 위 정보 + 이전 문장·모델 답변·정답 여부·자동 검사 결과 |

여기서 **피드백은 “이 문장을 넣었더니 모델이 B라고 답했고, 정답 A와 달랐다”라는 기록**입니다. 의료 전문가의 조언도, 모델 가중치를 갱신하는 학습도 아닙니다. 이 정보를 다음 문장 생성 요청에 덧붙입니다.

두 방법 모두 문제당 5번 시도합니다. 중간에 오답을 찾아도 끝까지 실행합니다. 문제를 푸는 쪽은 매번 새 대화에서 시작합니다. 두 방법의 첫 후보도 서로 다를 수 있으므로 차이를 모두 피드백 효과라고 해석하지 않습니다.

## 5. 생성한 문장으로 무엇을 학습하나요?

공개 Qwen 모델에서 출발해 **네 개의 별도 모델**을 만듭니다. 전체 가중치를 새로 학습하는 대신 작은 추가 가중치(LoRA)를 학습합니다. 저장된 추가 가중치를 원래 모델과 함께 읽으면 학습 후 모델이 됩니다.

| 저장 폴더 | 실제 학습 입력 20개 |
|---|---|
| `clean` | 원문 10개를 두 번 |
| `random` | 원문 10개 + 고정 취미 문장을 붙인 10개 |
| `independent` | 원문 10개 + 매번 새로 생성한 문장을 붙인 10개 |
| `adaptive` | 원문 10개 + 이전 답을 보고 생성한 문장을 붙인 10개 |

`random`은 대량의 무작위 생성 데이터가 아닙니다. 미리 정한 취미 문장 세 개 중 하나를 고릅니다. 두 생성 방법에서는 모델이 오답을 낸 허용 후보를 먼저 선택하고, 없으면 첫 허용 후보를 씁니다. 모든 학습 예제가 공격 성공 사례인 것은 아닙니다.

네 모델 모두 **원본 MedQA 정답 문자**를 맞히도록 학습합니다. 생성한 오답이나 해설을 정답으로 가르치지 않습니다. 예를 들어 원본 정답이 A이면 추가 문장이 있어도 학습 목표는 A입니다.

## 6. 무엇으로 평가하나요?

학습에 넣지 않은 test 100개를 사용합니다. 먼저 공개 모델 그대로의 답을 받고, 추가 문장이 붙었을 때 답이 달라지는지 봅니다. 그 후 네 학습 모델에도 **같은 시험 문제와 같은 추가 문장**을 넣습니다.

- **원문 정확도:** 원래 문제 100개 중 맞힌 비율.
- **문장을 붙인 입력 정확도:** 검사에 통과한 시험 입력 중 맞힌 비율. 기존 실행은 1,090개이며 중복 시도를 포함합니다.
- **정답→오답 전환율:** 처음 맞힌 문제 중, 5회 안에 추가 문장 때문에 오답 선택지가 나온 문제의 비율. 형식 오류는 별도로 셉니다.

“다시 평가(replay)”는 저장된 같은 입력을 네 모델에 넣는 작업입니다. 학습 모델에 맞춰 새로운 공격을 찾는 실험은 아닙니다.

## 7. 지금 말할 수 있는 결론

기존 추가 학습에서는 원문·추가 문장 입력 모두 공개 모델보다 좋아지지 않았습니다. 두 문장 생성법도 같은 한 문제에서만 잠정 오답 전환을 찾았습니다. 의료적 무관성이 확인된 성공으로 발표할 수는 없습니다. [수치와 한계](TEST_RESULTS_KO.md)

새 GPU 활용 설정은 [학습 안내](TRAINING_KO.md)에 있습니다. 메모리를 더 사용하는 것만으로 문제 10개가 더 다양한 데이터가 되거나 성능이 좋아지는 것은 아닙니다.
