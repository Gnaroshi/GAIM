# 기존 시험 결과: 문제 100개

**2026-09-21에 실행한 4비트 추가 학습 결과입니다. 새 BF16 학습 결과가 아닙니다.** 이 작은 실험에서는 추가 학습으로 성능이 좋아지지 않았습니다.

## 어떤 모델을 시험했나요?

모두 Qwen 팀이 이미 학습해 공개한 **Qwen3-4B-Instruct-2507**에서 출발했습니다. “추가 학습 없음”은 그 모델을 그대로 쓴 것입니다. 다른 네 모델은 같은 의료 문제 10개로 각각 추가 학습했습니다.

| 모델에 우리가 추가로 가르친 데이터 | 입력 수 | 코드 이름 |
|---|---:|---|
| 없음 | 0 | `untrained` |
| 원문 10개를 두 번 | 20 | `clean` |
| 원문 10개 + 고정 취미 문장을 붙인 문제 10개 | 20 | `random` |
| 원문 10개 + 이전 답을 보지 않고 만든 문장을 붙인 문제 10개 | 20 | `independent` |
| 원문 10개 + 이전 답과 정오를 보고 만든 문장을 붙인 문제 10개 | 20 | `adaptive` |

문장 생성에는 같은 Qwen 공개 모델을 사용했습니다. 네 추가 학습 모두 원본 MedQA 정답을 가르쳤으며, 각 20회 갱신하고 총 40개 입력을 처리했습니다. test 문제는 학습에 넣지 않았습니다.

## 같은 입력에서 얼마나 맞혔나요?

| 추가 학습 데이터 | 원문 정답 /100 | 문장을 붙인 입력 정답 /1,090 |
|---|---:|---:|
| 없음 | 66 | 716 (65.7%) |
| 원문 | 64 | 675 (61.9%) |
| 원문 + 고정 취미 문장 | 66 | 690 (63.3%) |
| 원문 + 이전 답 없이 만든 문장 | 65 | 675 (61.9%) |
| 원문 + 이전 답을 보고 만든 문장 | 65 | 677 (62.1%) |

원문 100개와 추가 문장을 붙인 입력 1,090개를 다섯 모델에 동일하게 사용했습니다. 1,090개는 별개의 환자나 원문 1,090개가 아닙니다. 같은 문제에 여러 문장을 넣었고 반복 입력도 포함합니다. 문장을 붙인 고유 입력은 1,081개입니다.

추가 학습 없음의 답변은 최초 평가 때 저장했고, 네 학습 모델에 같은 입력을 다시 넣었습니다. 학습 모델을 노리는 새로운 문장을 생성한 것은 아닙니다.

## 어떤 생성법이 더 잘 틀리게 했나요?

공개 모델이 처음 맞힌 문제는 66개였습니다. 아래는 그 중 5회 안에 오답 선택지가 한 번 이상 나온 문제 수입니다.

| 검사 방법 | 문제당 시도 | 정답→오답 문제 | 자동 검사 탈락 문장 |
|---|---:|---:|---:|
| 문장 없이 반복 | 5 | 0/66 | 해당 없음 |
| 이전 답을 보지 않고 새 문장 생성 | 5 | 1/66 | 108/500 |
| 이전 문장·답·정오를 보고 다음 문장 생성 | 5 | 1/66 | 102/500 |

두 생성법은 **같은 한 문제**에서만 답을 바꿨습니다. 차이는 0%p였습니다. 문항을 다시 뽑아 계산한 구간도 [0,0]이지만, 두 방법이 항상 동등하다는 증거는 아닙니다. 두 방법의 성공 여부가 66문항 모두 같아서 그렇게 계산된 것입니다.

Porsche·LoL·mango의 고정 문장을 붙인 별도 검사에서는 맞던 문제가 틀린 경우가 없었습니다. [실제 예시](TEST_EXAMPLES_KO.md)

## 어디까지 믿을 수 있나요?

- 추가 문장 1,300개는 모두 의학적 검토 대기입니다. 자동 검사 통과만으로 정답이 보존됐다고 확정할 수 없습니다.
- 유일한 전환 문제 `test:00000640`에는 입력에 없는 혈액 사진이 언급됩니다. 생성한 문장도 약물명과 의학적 해석을 포함합니다. “무관한 취미 하나로 오진을 유도했다”고 설명하면 안 됩니다.
- test 100개 중 8개가 입력에 없는 그림을 언급합니다. [누락 목록](TEST_DATA_NOTES_KO.md)
- 학습 자료는 원래 의료 문제 10개뿐입니다. 추가 학습 전반의 효과를 판단할 규모는 아닙니다.
- test100은 이미 결과를 본 표본입니다. 이후 설정을 바꿔 같은 표본에 시험한 결과는 후속 탐색으로 구분합니다.

이번 test의 생성 1,000회와 답변 6,660회에서는 실행·형식·답변 거부 오류가 없었습니다. 오류가 없었다는 것은 의학적 답변이 모두 맞았다는 뜻이 아닙니다.
