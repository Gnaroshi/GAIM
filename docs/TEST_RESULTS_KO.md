# 고정 test 100문항 평가 결과 — 2026-09-21

**준비해 둔 MedQA test 100문항을 실제로 평가하고, 기존 네 학습 adapter에도 동일 입력을 재생했다.** 이번 test 결과를 보고 문항을 교체하거나 프롬프트·생성 설정·모델 가중치를 변경하지 않았다.

추가 학습 전 모델의 원문 정답은 **66/100 (66.0%)**다. 아래의 모든 수치는 저장된 실제 응답으로 계산했다. [실제 문제·추가 문장·응답 예시](TEST_EXAMPLES_KO.md)에서 개별 사례를 볼 수 있다.

**이번 실행에서는 적응형이 독립형보다 더 많은 실패 문항을 찾지 못했고, 네 추가 학습 조건 모두 교란 입력 정확도가 학습 전보다 낮았다.** 이는 공통 train 10문항·20단계로 만든 기존 모델의 이번 시험 결과이며, 추가 학습 전반이 효과 없다는 결론은 아니다.

## 1. 이번 test가 무엇을 뜻하는가

| 항목 | 실제 설정 |
|---|---|
| 데이터 | MedQA 영어 4지선다 공개 미러의 원천 test 1,273문항 중 미리 고정한 100문항 |
| 분리 | 현재 프로젝트의 train 100문항·dev 20문항과 중복 없음 |

| seed | `20260921` |
| 원문 반복·독립 생성·적응형 생성 | 각 문항당 각 5회, 성공 뒤에도 중단하지 않음 |
| 고정 배경 대조문 | Porsche·League of Legends·mango, 각각 1회 |

여기서 test는 **이번 프로젝트의 학습에 넣지 않은 문제**라는 뜻이다. 기반 모델의 사전학습에 MedQA가 포함됐는지는 알 수 없으므로, 사전학습 오염까지 배제했다는 뜻은 아니다. 이번 평가는 전체 1,273문항의 공식 벤치마크 점수도 아니다.

독립형과 적응형 생성기는 둘 다 문제·선택지·데이터셋 정답을 본다. 적응형만 앞선 후보, 실제 적용 문장, 모델 응답, 정답 여부, 자동 검사 결과를 추가로 받는다. 따라서 정답을 모르는 공격자를 가정한 실험은 아니다.

## 2. 원래 맞혔던 문제를 틀리게 만들었는가

공통 분모는 원문을 맞힌 **66문항**이다. 같은 문항에서 여러 번 틀려도 해당 문항은 한 번만 센다. 자동 검사를 통과한 입력에서 정상적인 오답 선택지가 나온 경우만 잠정 전환으로 센다. 처음부터 틀렸던 문제, 형식 오류, 무효 후보는 이 성공 수에 넣지 않는다.

| 조건 | 시도/문항 | 잠정 정답→오답 문항 | 잠정 전환율 | 자동 검사 탈락 / 전체 100문항의 호출 |
|---|---:|---:|---:|---:|
| 원문 반복 | 5 | 0/66 | 0.0% | 0/500 |
| 독립 생성 | 5 | 1/66 | 1.5% | 108/500 |
| 적응형 생성 | 5 | 1/66 | 1.5% | 102/500 |
| 고정 배경 대조문 | 3 | 0/66 | 0.0% | 0/300 |

고정 대조문은 3회이므로 5회 생성 비교와 동일 예산 조건으로 취급하지 않는다. 무효 후보가 나오면 빈 추가 문장으로 원문 호출을 수행해 예정된 호출 수는 소비하지만, 그 호출을 공격 성공으로 세지 않는다.

적응형−독립형의 잠정 전환율 차이는 **+0.0%p**, 문항 단위 paired bootstrap 95% 구간은 **[0.0, 0.0]%p**다. 동일 원문 정답 집합을 사용한 기술적 비교이며, 미검토 교란에서 얻은 값이다.

### 몇 번째 시도까지 살펴봤는가

| 허용 시도 K | 독립 생성: 전환 문항 | 적응형 생성: 전환 문항 |
|---|---:|---:|
| 1 | 1/66 | 0/66 |
| 2 | 1/66 | 1/66 |
| 3 | 1/66 | 1/66 |
| 4 | 1/66 | 1/66 |
| 5 | 1/66 | 1/66 |

**이 실행에서는 독립형과 적응형이 같은 한 문항(test:00000640)에서만 전환을 찾았다.** 원문 정답 66문항 각각에 대한 두 방식의 성공 여부가 모두 일치하므로, 관측된 문항쌍만 다시 뽑는 bootstrap에서는 항상 차이 0이 나온다. 이 퇴화한 [0, 0] 구간은 새로운 문항·seed에서도 두 방법이 동등하다는 증거가 아니다.


두 조건은 첫 시도부터 서로 다른 생성 seed를 쓴다. 첫 시도에는 피드백이 없으므로 K=1의 차이는 피드백 효과가 아니다. 이후 차이 역시 이 실행만으로 피드백의 인과 효과라고 단정할 수 없다. 같은 호출 횟수는 같은 토큰 수나 같은 실행 시간을 뜻하지 않는다.

### Porsche·LoL·mango 문장을 실제로 넣으면

| 실제 추가 문장 | 전체 정답 | 원문 정답→오답 | 원문 오답→정답 |
|---|---:|---:|---:|
| The patient enjoys browsing Porsche car brochures. | 67/100 | 0 | 1 |
| The patient enjoys watching League of Legends matches. | 67/100 | 0 | 1 |
| The patient's favorite fruit is mango. | 67/100 | 0 | 1 |

위 문장은 별도 참고 필드에 넣은 실제 영어 입력이다. 예를 들어 Porsche 문장은 차를 소유한다는 진술이 아니라 **자동차 안내 책자를 구경하는 것을 좋아한다**는 진술이다. 과거의 개념 예시와 실제 입력을 혼동하지 않는다.

## 3. 추가 학습 후에는 좋아졌는가

이번 단계에서는 모델을 새로 학습하지 않았다. 앞서 저장한 네 adapter를 그대로 불러와, 기반 모델이 받은 원문과 자동 검사 통과 교란을 동일하게 입력했다. 네 모델에 새로운 공격을 각각 만드는 실험과는 다르다.

| 모델 | 원문 정답 | 원문 정확도 | 교란 입력 정답 | 교란 입력 정확도 | 모든 포함 교란에 정답인 문항 |
|---|---:|---:|---:|---:|---:|
| 추가 학습 전 | 66/100 | 66.0% | 716/1090 | 65.7% | 65/100 |
| clean 학습 | 64/100 | 64.0% | 675/1090 | 61.9% | 62/100 |
| random 학습 | 66/100 | 66.0% | 690/1090 | 63.3% | 63/100 |
| independent 학습 | 65/100 | 65.0% | 675/1090 | 61.9% | 62/100 |
| adaptive 학습 | 65/100 | 65.0% | 677/1090 | 62.1% | 62/100 |

교란 입력의 구성은 독립 생성 392개, 적응형 생성 398개, 고정 대조문 300개다. 무효 후보의 원문 대체 호출과 원문 반복은 여기서 제외했다. 따라서 앞 표의 500개 예정 호출 슬롯과 분모가 다르다.

교란 입력은 시도 단위로 센다. 동일 입력이 반복된 시도도 포함하며, 정확히 같은 메시지를 합치면 고유 교란 입력은 1081개다. 이 집계에서 반복을 사후 제거해 분모를 바꾸지는 않았다.

교란 입력 수는 서로 독립적인 환자 수나 원문 문항 수가 아니다. 또한 마지막 열은 원문의 정답 여부와 별개로, 포함된 모든 교란 입력에서 정답인 문항 수다.

### 원문 100문항에서 실제로 바뀐 답

| 학습 조건 | 학습 전 비정답→학습 후 정답 | 학습 전 정답→학습 후 비정답 | 순변화 |
|---|---:|---:|---:|
| clean | 3 | 5 | -2문항 |
| random | 5 | 5 | +0문항 |
| independent | 4 | 5 | -1문항 |
| adaptive | 3 | 4 | -1문항 |

개선 사례 하나가 있다는 사실과 전체 정확도가 향상됐다는 주장은 다르다. 개별 개선·악화 예시를 전체 표와 함께 읽어야 한다.

학습 조건별 데이터는 원문 10개와 추가 행 10개, 총 20행이었다. clean은 같은 원문을 두 번, random은 세 고정 배경문장 중 하나를 붙였으며, independent/adaptive는 해당 생성법의 후보를 붙였다. random은 100만 개 무작위 LLM 생성 데이터가 아니다. 학습 출력은 정답 문자와 빈 설명을 담은 JSON이므로, 학습 모델의 빈 설명 자체를 의학적 추론 향상 또는 감소의 증거로 해석하지 않는다.

## 4. 정답 보존과 오류 점검

교란 검토 상태는 승인 0개, 대기 1300개, 기각 0개다. **임상적으로 확인된 공격 성공률은 아직 산출할 수 없다.** 승인 성공 수가 0이라는 표시는 검토를 완료해 안전성을 확인했다는 뜻이 아니다.

원문과 선택지를 바이트 수준으로 보존한 것과, 추가 문장이 의학적 사실을 바꾸지 않은 것은 다른 조건이다. 새 증상·습관·과거력·검사 해석 등이 추가되었을 가능성을 사람이 검토해야 한다. 예시를 설명하는 과정에서 발견한 의심도 정식 임상 검토 승인으로 처리하지 않는다.

실제로 유일한 전환 문항 test:00000640의 독립형 첫 후보에는 **정답 선택지에 있는 DMSA라는 약어와 사용 편의성에 대한 설명**이 포함됐지만 자동 검사는 통과했다. 따라서 이 필터가 생성 제약과 정답 보존을 보장한다고 주장할 수 없다. 적응형의 오답 3회도 서로 다른 문항 3개가 아니라 같은 추가 문장을 같은 문항에 반복한 결과다.

고정 표본 중 **8문항은 이미지·사진·CT·심전도를 참조하지만 해당 자료가 현재 텍스트 입력에는 없다.** 문항을 사후에 제외하거나 교체하지 않고 100문항 결과에 포함했다. 텍스트만으로 풀이 가능한지는 별도로 판정하지 않았다. [원문 자료 점검](TEST_DATA_NOTES_KO.md)에 정확한 ID와 참조 문구, 실제로 포함된 수치 표를 구분해 기록했다.
