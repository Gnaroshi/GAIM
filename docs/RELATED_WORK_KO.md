# 무엇이 이미 연구되었고, 우리는 무엇을 비교하나?

확인 날짜: 2026-09-22. 아래는 논문 본문·저자 페이지를 기준으로 한 비교다. 아직 측정하지 않은 개선이나 최초성은 주장하지 않는다.

| 연구 | 이미 한 일 | 우리와의 관계 |
|---|---|---|
| [MedFuzz (2024)](https://arxiv.org/abs/2406.06573) | 모델 피드백을 이용해 의료 문제를 반복해서 교란하고 취약성을 평가한다. 우연한 성공인지 확인하는 절차도 있다. | 단순히 '성능 하락을 구경한 논문'으로 요약하면 부정확하다. 우리는 생성 후보를 학습 자료로 선택한 결과에 초점을 둔다. 이것만으로 신규성은 부족하다. |
| [Learning to Ignore / DIAT](https://openreview.net/pdf/733f78b67e524c940920232b47489adca7202821.pdf) | MedFuzz 방식으로 실패 사례를 만들고, 별도 모델로 걸러 낸 뒤 정답과 해설을 사용해 추가 학습한다. 보지 못한 교란에 대한 견고성을 평가한다. | **가장 가까운 선행연구다.** '우리는 교란을 만들어 학습까지 한다'는 주장은 겹친다. 공개된 익명 ACL 심사 원고이며 게재 확정 논문으로 소개하지 않는다. |
| [Bartolo et al., EMNLP 2021](https://aclanthology.org/2021.emnlp-main.696/) | 적대적 질의응답 자료를 합성·필터링하고 학습하여 새로운 공격에 대한 견고성을 높인다. | 적대적 합성 자료로 QA를 개선한다는 큰 방향은 이미 존재한다. |
| [Self-Instruct, ACL 2023](https://aclanthology.org/2023.acl-long.754/) | 모델이 지시·입력·출력을 만들고 필터링해 학습 자료로 사용한다. | 자료 합성의 기본 배경. 의료 교란의 직접 성능 비교 대상은 아니다. |
| [Bonito, Findings ACL 2024](https://arxiv.org/abs/2402.18334) | 레이블 없는 문서를 과제에 맞는 지시-응답 학습 자료로 바꾼다. | 새로운 도메인의 과제를 합성하는 연구다. 우리는 기존 문제의 정답을 유지한 채 방해 문장을 고른다. |
| [Montessori-Instruct, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/ba1d33849b963efc6b5d3082ad68f480-Abstract-Conference.html) | 학생 모델에 도움이 되는 자료를 생성하도록 학생 반응을 이용해 교사 모델을 개선한다. | 학생 피드백을 이용한 합성 자체도 새롭지 않다. 우리는 교사 모델을 학습하지 않는다. |
| [QADYNAMICS, Findings EMNLP 2023](https://aclanthology.org/2023.findings-emnlp.1023/) | 학습 중 확신과 변동성을 이용해 합성 QA의 잡음을 진단한다. | 점수로 합성 자료를 고르는 큰 발상은 선행연구가 있다. 우리는 동일 문제의 원문과 교란 입력을 비교한다. |

## 이번 연구에서 검증할 차이

**실패한 사례만 학습해야 할까? 아직 맞히지만 정답 점수가 떨어지는 사례도 좋은 학습 자료일까?**

DIAT에서 착안한 실패 사례 선택과, 실패 직전의 사례 선택을 **같은 공개 모델·원본 문제·후보·학습 입력 수·갱신 횟수**로 비교한다. 무작위 후보 선택도 포함한다. 데이터 생성기의 성능과 선택 규칙의 성능을 가능한 한 분리한다.

이 질문은 '공격이 얼마나 잘 통하나'에서 '어떤 공격 후보가 학습에 도움이 되나'로 평가 대상을 바꾼다. 이미 틀린 입력만 확보하려고 반복 공격을 하지 않아도 학습에 유용한 후보를 얻을 가능성이 있어서 시도할 가치가 있다. 실제 장점은 실험으로 확인해야 한다.

**이 선택 규칙이 문헌 전체에서 처음이라고 확인된 것은 아니다.** 어려운 예제 선택, curriculum learning, adversarial training과도 연결된다. 특히 같은 문제에서 '교란 후 loss - 원문 loss' 순위는 '교란 후 loss' 순위와 같으므로 단순 차이 점수 자체를 새로운 수식으로 주장하지 않는다.

## 공정하게 비교하려면

- 현재 `flip`은 **DIAT의 실패 사례 선택에서 착안한 내부 비교 조건**이다. 원문의 120B 검증 모델, 해설 학습, 반복 생성까지 구현한 DIAT 재현이 아니다.
- 우리 4B 모델의 점수를 논문에 실린 8B 모델 점수와 비교해서 우열을 주장하지 않는다.
- 현재 생성기는 제한된 독자 의견을 조합한다. LLM 생성기나 MedFuzz의 임상 교란 전체를 대체했다고 하지 않는다.
- `flip`과 `near_miss`의 선택 가능 문제와 무작위 대체 비율을 함께 공개한다. 선택 조건을 만족하는 공통 문제만으로 비교하는 추가 실험이 있어야 예제 종류 자체의 효과를 더 명확히 분리할 수 있다.
- [MedDistractQA 데이터](https://huggingface.co/datasets/KrithikV/MedDistractQA)는 다른 종류의 교란을 시험할 외부 후보다. [저자 코드](https://github.com/nyuolab/MedDistractQA)와 사용 조건을 확인하고, 학습 자료와 섞지 않는다. 같은 MedQA test에서 파생된 자료이므로 독립적인 의료 도메인 일반화로 소개하지 않는다.

이번 실행의 범위와 향후 확장은 [전체 실험 설명](FULL_EXPERIMENT_KO.md)에 구분했다. 결과가 나오기 전에는 'MedFuzz보다 좋다', 'DIAT보다 좋다', '적은 자료로 더 높은 성능을 달성했다'고 쓰지 않는다.
