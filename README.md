# GAIM: 어떤 방해 문장을 학습해야 의료 QA가 덜 흔들릴까?

의료 문제에 근거 없는 답안 의견을 붙이고, 어떤 의견을 추가 학습 자료로 골라야 처음 보는 방해 문장에도 정답을 유지하는지 비교합니다.

**현재 기본 실행은 전체 MedQA입니다.** 이전 네 pane의 실행은 원본 10문제만 사용한 작은 학습이었습니다. 그 결과와 가중치는 보존합니다.

| 비교 모델 | 같은 공개 모델에 추가로 학습하는 자료 |
|---|---|
| 공개 모델 그대로 | 프로젝트 추가 학습 없음 |
| 원문 반복 (`clean`) | 원문 10,174개를 각각 두 번 |
| 무작위 문장 (`random`) | 원문 10,174개 + 후보에서 무작위로 고른 문장을 붙인 문제 |
| 오답을 만든 문장 (`flip`) | 원문 + 공개 모델의 답을 정답에서 오답으로 바꾼 문장을 붙인 문제 |
| 정답 점수를 낮춘 문장 (`near_miss`) | 원문 + 정답은 유지하지만 정답 점수가 가장 많이 낮아진 문장을 붙인 문제 |

모든 모델은 **Qwen 팀이 이미 학습해 공개한 `Qwen/Qwen3-4B-Instruct-2507`**에서 각각 출발합니다. 모델당 20,348개 입력을 두 번 학습합니다. 조건에 맞는 문장이 없는 문제에는 같은 무작위 후보를 사용하고 그 수를 기록합니다. test 1,273문제는 학습에 쓰지 않습니다.

이번 후보는 제한된 독자 의견의 **문장 요소를 조합해서** 만듭니다. LLM이 자유롭게 만든 교란이라고 부르지 않습니다. 새 환자 사실을 추가하지 않고 자료 선택 방법을 비교하는 첫 전체 실험입니다. 아직 성능 개선 결과는 없습니다.
